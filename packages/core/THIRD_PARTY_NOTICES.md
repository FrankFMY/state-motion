# Third-party notices

The core has no runtime dependencies and bundles no third-party runtime code.
The optional adapter requires Svelte 5.57.0 as a peer and csstype 3.2.3 for CSS
property declarations. Their runtime/type files are resolved from those packages,
not copied into this distribution. The applicable notices are reproduced below.
Build and test tools are development dependencies recorded in bun.lock; they are
not included in either tarball.
